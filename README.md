## 🚀 Overview

Leaders Network is a modern, enterprise-grade website showcasing comprehensive technology solutions. Built with Next.js 14 and TypeScript, featuring a sophisticated dark theme, interactive animations, and a comprehensive blog system with commenting functionality.

**Since 2005**, Leaders Network has been empowering organizations with enterprise-grade software, strategic consulting, and digital transformation solutions across Nigeria and beyond.

## 🛠️ Technology Stack

### Frontend
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Custom component library
- **Icons:** React Icons
- **Animations:** CSS transitions + Custom particle system

### Features
- **Blog System:** Dynamic routing with [slug] pages
- **Comments:** Real-time commenting system
- **Theme:** Dark/Light mode toggle
- **Navigation:** Responsive header with mobile menu
- **Forms:** Contact forms with validation
- **SEO:** Meta tags, Open Graph, Twitter Cards

### Performance
- **Fonts:** Next.js font optimization with Inter
- **Images:** Next.js Image optimization
- **Code Splitting:** Automatic with Next.js App Router
- **Bundle Analysis:** Optimized build outputs

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ and npm/yarn/pnpm
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/leaders-network.git
   cd leaders-network
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open your browser**
   ```
   http://localhost:3000
   ```

### Build for Production

```bash
npm run build
npm run start
```
